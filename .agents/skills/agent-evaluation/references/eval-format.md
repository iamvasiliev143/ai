# Формат эталонной задачи и отчёта оценки

## Эталонная задача

```markdown
## <ID> <название>

- Навык или агент: <имя>
- Тип: типичная | граничная | ловушка
- Вход: <описание задачи, данные — только синтетические>
- Разрешённые файлы: <пути>
- Критерии приёмки:
  1. <критерий> — проверка: <команда, тест или ссылка на строку документа>
  2. ...
- Инвариант под риском (для ловушки): <ссылка на AGENTS.md или ADR>
- Ожидаемые артефакты: <код, тест, отчёт, документ>
- Ожидаемые замечания (для ревьюеров): <файл:строка — что не так> для каждого внесённого в diff дефекта; критерий — найдено, найдено с неверной серьёзностью, пропущено, ложное замечание
- Базовая линия: <тот же агент без навыка | общий агент без профиля>
```

## Таблица результатов

| Задача | Критерий | С навыком | Без навыка | Доказательство |
| --- | --- | --- | --- | --- |
| E-1 | 1 | выполнен | не выполнен | вывод `npm run check` |
| E-1 | инвариант | соблюдён | нарушен | файл:строка |

## Причины провала

| Категория | Признак | Исправление |
| --- | --- | --- |
| Навык | Нет шага, неверное правило, критерий «Готово» не проверяем | Изменить навык, прогнать регрессию |
| Контекст | Агент не прочитал канонический документ | Ссылка в «Прочитай сначала», короче путь до документа |
| Модель | Тот же навык и контекст дают нестабильный результат | Решение владельца о модели и effort |
| Инструмент | Нет доступа, команда падает, ограничение песочницы | Права или окружение |
| Процесс | Нет критериев приёмки, неверное разбиение задачи | Задача возвращается владельцу |
