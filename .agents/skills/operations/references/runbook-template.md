# Шаблон регламента

Один регламент — один сигнал или одна процедура. Действия — только документированные в проекте. Регламент выполняет дежурный по шагам без участия автора изменения; агенты регламенты в продакшене не выполняют.

| Раздел | Содержание |
| --- | --- |
| Сигнал | Метрика или запрос, порог, источник порога (документ или «вопрос владельцу») |
| Исполнитель | Роль дежурного; кто может выполнять действия с побочными эффектами |
| Признаки | Что видит дежурный: алерт, панели, журналы |
| Проверка | Шаги, отличающие сбой от штатного состояния; что сохранить как доказательство (ID запросов и операций, время, версия, область) |
| Действия | Нумерованные шаги со ссылкой на документ, где действие определено: откат версии, отключение флагом, ограничение нагрузки, переключение на резерв |
| Что продолжает работать | Что остаётся доступным и в каком объёме |
| Возобновление | Условие возврата в штатный режим, необходимые сверки, кто принимает решение |
| Эскалация | Когда и кому передаётся; какие данные передать |
| Протокол | Что записывается: время, область, инициатор, версия, причина, решения, итоги сверки |
| Статус | проект / проверен учением <дата> |
