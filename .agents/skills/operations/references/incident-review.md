# Шаблон разбора инцидента

Разбор пишется без поиска виновных: цель — меры, которые не дают повториться. Факты — из журналов, метрик, протоколов действий и восстановления, не по памяти. Персональные данные — только маскированные; секретов и токенов в разборе нет.

| Раздел | Содержание |
| --- | --- |
| Сводка | Что произошло и когда; затронутые сервисы, функции и области |
| Влияние | Сколько пользователей и операций затронуто, длительность, потерянные или искажённые данные, нарушенные SLO |
| Хронология | Начало, обнаружение, эскалация, действия, восстановление, возобновление — с источником каждой записи |
| Восстановление | Точка восстановления, результаты сверки данных, что пришлось исправить вручную |
| Первопричина | Техническая причина и почему её не поймали тесты, ревью и мониторинг |
| Что сработало | Сигналы, регламенты и действия, которые помогли |
| Что не сработало | Пропущенные сигналы, неточные регламенты, задержки эскалации |
| Меры | Мера, владелец, задача или ADR, срок по решению владельца |
| Открытые вопросы | Что не удалось установить и кто выясняет |
