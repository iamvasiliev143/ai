# Отчёт замеров производительности

Шаблон для шага 7 навыка `performance`. Пустое поле не удаляется: пишется «не измерялось» с причиной. Метрики, не применимые к проекту, удаляются с пометкой в «Профиле», почему.

## Серверная часть и фоновые процессы

```markdown
# Замер: <изменение или сценарий приёмки>

- Вопрос: регрессия / улучшение / приёмка по бюджету — что подтверждаем
- Порог и источник: ссылка на документ или «порог не утверждён» (вопрос владельцу: …)
- Сборка до / после: коммит или digest образа

## Профиль
- Смесь операций и доли:
- Параллельные пользователи или запросов в секунду; распределение данных и «горячие» ключи:
- Внешние зависимости: задержка, доля отказов, повторы:
- Прогрев, длительность, число повторов прогона:
- Среда: ресурсы, версия хранилища и параметры, размеры пулов:
- Инструмент: название и версия (до ADR — «предварительный, требует ADR»)
- Сырые результаты: путь

| Метрика | До | После | Изменение |
| --- | ---: | ---: | ---: |
| p50 / p95 / p99 по операции, мс | | | |
| Доля ошибок и тайм-аутов по операции, % | | | |
| CPU, пик, % | | | |
| Память, пик, МБ | | | |
| Задержка цикла событий или занятость потоков, p99 | | | |
| Время запроса или транзакции p95, мс | | | |
| Ожидание блокировок p95, мс | | | |
| Ожидание внешних зависимостей p95, мс | | | |
| Занятость пулов соединений, пик | | | |
| Длина очереди и возраст старейшей задачи, с | | | |

## Место затрат
Трасса, план запроса или профиль CPU — что показывает; либо «узкое место не найдено» и перечень проверенного.

## Итог
соответствует порогу документа X / не соответствует / порог не утверждён

## Остаточные риски и открытые вопросы
```
