# Отчёт передачи

Отчёт пишется в описании PR (шаблон — `.github/pull_request_template.md`) или в комментарии к задаче. Передаются ссылки на артефакты, а не переписка.

| Поле | Что писать |
| --- | --- |
| Задача | Ссылка на issue или страницу задачи |
| Результат | Что сделано, одним-двумя предложениями, в терминах критериев приёмки |
| Изменённые файлы | Список или ссылка на diff; отметка, если вышли за разрешённые файлы и с чьего согласования |
| Доказательства проверок | Команды и их итог: `npm run check` — код 0, число тестов; ручные проверки — шаги и результат |
| Ограничения | Что не сделано или сделано частично и почему |
| Открытые вопросы | Вопросы владельцу со ссылками на строки документов |
| Независимое ревью | Кто проверяет: `code-reviewer`; `security-reviewer` — если затронуты доступ, секреты, границы доверия, инварианты |
| Следующий владелец | Кто принимает работу дальше |

Формулировки результата — фактические: «тест X проходит», «соответствует документу Y». Без оценок вроде «всё работает идеально».
