# Глоссарий

Термины проекта. Новый термин сначала добавляется сюда, затем используется в документах, коде и навыках. Порядок — алфавитный; колонка «Где подробнее» ведёт на канонический документ.

## Термины

| Термин | Определение | Где подробнее |
| --- | --- | --- |
| ADR | Architecture Decision Record — запись архитектурного решения: контекст, варианты, решение, последствия. | [ADR](adr/README.md) |
| Агент | Исполняемый профиль AI-агента с одной зоной ответственности и набором навыков; канон — `.agents/agents/`. | [Агенты](agents.md) |
| Канонический документ | Единственный документ, где живёт факт, число или правило; остальные ссылаются на него. | [CONTRIBUTING](../CONTRIBUTING.md#документация) |
| Навык | Методика работы агента в `.agents/skills/<имя>/SKILL.md`: шаги, критерии готовности, проверки. | [Агенты](agents.md) |
| Независимое ревью | Проверка результата другим агентом или человеком в отдельной сессии со свежим контекстом; автор своё изменение не одобряет. | [Рабочий процесс](agents.md#рабочий-процесс) |
| Отчёт передачи | Результат, изменённые файлы, доказательства проверок, ограничения, открытые вопросы и следующий владелец. | [Рабочий процесс](agents.md#задача-агента) |
| Разрешённые файлы | Файлы и каталоги, которые исполнитель задачи может менять. | [Рабочий процесс](agents.md#задача-агента) |
| MCP | Model Context Protocol — протокол подключения инструментов к агентам; в проекте — серверы GitHub и Notion. | [Правила и полномочия](agents.md#правила-и-полномочия) |
