# Участие в разработке

## Код

Команды запуска, сборки и проверок — в [README](README.md). Перед сдачей изменения выполняйте `npm run check` из корня репозитория. Код и тесты — в одном изменении. Прямая запись в `main` запрещена: работа идёт в ветке и через pull request.

Сообщения коммитов — по [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.

## Документация

- Документация продукта находится в `docs/`, оглавление — [docs/README.md](docs/README.md). Каждый новый документ добавляйте в оглавление.
- Пишем кратко, без повторов. Каждый факт и число живут в одном документе, остальные ссылаются на него.
- Термины используем так, как они определены в [глоссарии](docs/glossary.md). Новый термин сначала добавляем в глоссарий.
- Архитектурные решения оформляем как ADR в `docs/adr/` по [правилам](docs/adr/README.md). Принятый ADR не переписываем, а заменяем новым.
- Один процесс — один файл. Планы, трекеры и черновики не размножаем: обновляем существующий.
- Статус документа указываем нейтрально, например «Статус: проект спецификации, реализация не начата». Фактические результаты фиксируются только по доказательствам.
- Ссылки только относительные и только внутри репозитория; внешние ресурсы — полными URL. Проверка — `npm run check:docs`.

## Работа с AI-агентами

Роли агентов, их навыки, зоны ответственности и рабочий процесс — в [docs/agents.md](docs/agents.md). Используем агентов для вариантов архитектуры, проверок, контрактов, тестов и независимого ревью.

- Каждой задаче задаём владельца, разрешённые файлы, входной контракт и критерии приёмки.
- Автор не одобряет собственный результат: ревью — другой агент в отдельной сессии со свежим контекстом.
- Изменения авторизации, секретов, границ доверия и инвариантов из [AGENTS.md](AGENTS.md#инварианты-нарушение--блокер) требуют независимой проверки и одобрения ответственного человека.
- Агентам даём синтетические данные и тестовую среду. Ключи, персональные данные, доступ к продакшену, слияние и релиз остаются под контролем людей.
- Канон агентов и навыков — `.agents/`; файлы в `.claude/agents/`, `.claude/skills/` и `.codex/agents/` генерируются и руками не правятся.
